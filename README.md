# SmartMetra AI

### AI-powered Intelligent Assistant for Indian Standards and BIS Services for Industries and Consumers

SmartMetra AI is a software-based AI assistant designed to help consumers, industries, and authorized users find and understand relevant Indian Standards and BIS services.

The system allows users to start with a product, product image, or natural-language question instead of requiring them to already know the relevant IS number. It uses OCR, product understanding, semantic search, and a standards knowledge base to identify potentially relevant standards and provide source-backed information.

> This project is developed as a prototype for Smart India Hackathon 2026.

---

## Problem Statement

**SIH26107 — AI-powered Intelligent Assistant for Indian Standards and BIS Services for Industries and Consumers**

Finding the correct Indian Standard or BIS service can be difficult when users do not know the applicable standard number or technical terminology.

Users may need to search through standards, certification information, testing requirements, laboratories, and other BIS resources separately.

SmartMetra AI aims to provide a single intelligent interface where a user can describe or scan a product and receive relevant standards and BIS-related guidance.
